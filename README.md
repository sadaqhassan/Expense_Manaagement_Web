🔐 Authentication Flow
User login/register
JWT token generated
Token stored in HTTP-only cookie
Protected routes verify token
Auto logout when token expires

📦 Installation
Clone Repository
git clone your-repo-link
Install Frontend
cd client
npm install
Install Backend
cd server
npm install
🔑 Environment Variables

Create .env

PORT=4000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
▶️ Run Project
Backend
npm run server
Frontend
npm run dev
